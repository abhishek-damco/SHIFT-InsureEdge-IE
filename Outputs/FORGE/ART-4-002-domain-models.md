## Section 1: Shared Conventions

### 1.1 Base Entity

All entities inherit from `BaseEntity`:

```
BaseEntity
  Properties:
    - CreatedOn : DateTimeOffset (not nullable) — UTC; set on INSERT
    - CreatedBy : int (not nullable) — UserId of creator
    - ModifiedOn : DateTimeOffset? (nullable) — NULL until first update
    - ModifiedBy : int? (nullable) — NULL until first update
    - IsActive : bool (not nullable, default true) — soft-delete flag
```

`BaseEntity` is NOT mapped to a separate table — its columns are included in every entity's table.

### 1.2 Tenant-Scoped Entity

All entities subject to multi-tenant isolation inherit from `TenantEntity : BaseEntity`:

```
TenantEntity : BaseEntity
  Properties:
    - ClientId : int (not nullable) — FK to identity.client (ADR-003)
```

EF Core global query filter applied: `WHERE client_id = @clientId` (bypassed for PlatformAdmin role per ADR-003 §4).

### 1.3 Value Objects

| Value Object | Properties | Validation Rule |
|---|---|---|
| `Money` | Amount : decimal(18,4), Currency : string (ISO 4217, default "USD") | Amount >= 0; Currency required |
| `PolicyNumber` | Value : string | Format: alphanumeric, max 20 characters; unique per ClientId |
| `UserCode` | Value : string | Format: "IE" + 4-digit zero-padded seq (IE0001 through IE9999); FR-D5-003 |
| `Address` | Line1, Line2?, City, State (2-char), ZipCode (5-digit), Country (default "US") | Line1, City, State, ZipCode required |

Value objects are stored as owned entity types in EF Core (no separate table — columns embedded in owning entity's table).
