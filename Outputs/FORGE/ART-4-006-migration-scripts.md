## Type Mapping Reference

| SQL Server Type | PostgreSQL Type | Notes |
|---|---|---|
| `uniqueidentifier` | `uuid` | Use `uuid_generate_v4()` for new UUIDs; migrate existing as-is |
| `bit` | `boolean` | 0 → false; 1 → true |
| `datetime` | `timestamp without time zone` | **Sentinel 1900-01-01 → NULL** (NFR-011) |
| `datetime2` | `timestamp without time zone` | Same sentinel rule |
| `smalldatetime` | `timestamp without time zone` | Same sentinel rule |
| `nvarchar(max)` / `varchar(max)` | `text` | Unbounded |
| `nvarchar(n)` / `varchar(n)` | `varchar(n)` | Length preserved |
| `int` | `integer` | Direct |
| `bigint` | `bigint` | Direct |
| `smallint` | `smallint` | Direct |
| `tinyint` | `smallint` | PostgreSQL has no tinyint |
| `decimal(p,s)` / `numeric(p,s)` | `numeric(p,s)` | Precision and scale preserved |
| `money` | `numeric(18,4)` | SQL Server money → PostgreSQL numeric |
| `float` / `real` | `double precision` / `real` | |
| `bit` → bool flags | `boolean` | All IsXxx, AllAccess columns |
| `varbinary(max)` | `text` (BlobPath) | Binary extracted to Azure Blob; column becomes blob path |
| `varbinary(n)` | `bytea` (if small inline) | Assess per table; most cases → Blob extraction |
| `IDENTITY(1,1)` | `GENERATED ALWAYS AS IDENTITY` | Auto-increment |
| `NOLOCK` hint | (removed) | PostgreSQL MVCC eliminates need |
| `dbo.` prefix | `{schema}.` | Replace with domain schema prefix |

### 1.2 Representative Table DDL Patterns

**HUMAN_VALIDATION_REQUIRED — The following are structural patterns. Actual DDL is generated by EF Core migrations. DBA must review generated migrations before `dotnet ef database update`.**

**Pattern: Tenant-scoped table with timestamp and sentinel conversion**
```sql
-- Example: policy.policy
CREATE TABLE policy.policy (
    policy_id            INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    policy_number        VARCHAR(20)     NOT NULL,
    policy_type_id       INTEGER         NOT NULL REFERENCES policy.policy_type(policy_type_id),
    policy_status_id     INTEGER         NOT NULL REFERENCES policy.policy_status(policy_status_id),
    effective_date       TIMESTAMP       NOT NULL,
    expiration_date      TIMESTAMP       NOT NULL,
    bind_date            TIMESTAMP,                   -- NULL until bound
    cancellation_date    TIMESTAMP,                   -- NULL unless cancelled; 1900-01-01 converted to NULL
    intermediary_id      INTEGER         REFERENCES distribution.intermediary(intermediary_id),
    writing_company_id   INTEGER         REFERENCES policy.writing_company(writing_company_id),  -- typo corrected NFR-012
    client_id            INTEGER         NOT NULL REFERENCES identity.client(client_id),
    account_id           INTEGER,                     -- legacy reference; see DBT-3-MIG-001
    policy_fee           NUMERIC(18,4)   NOT NULL DEFAULT 195.00,
    is_renewal           BOOLEAN         NOT NULL DEFAULT FALSE,
    original_policy_id   INTEGER         REFERENCES policy.policy(policy_id),
    created_on           TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    created_by           INTEGER         NOT NULL,
    modified_on          TIMESTAMPTZ,
    modified_by          INTEGER,
    is_active            BOOLEAN         NOT NULL DEFAULT TRUE
);

-- Required indexes
CREATE UNIQUE INDEX ix_policy_number_client ON policy.policy(policy_number, client_id);
CREATE INDEX ix_policy_client_status ON policy.policy(client_id, policy_status_id);
CREATE INDEX ix_policy_client_expiry ON policy.policy(client_id, expiration_date);
```

```sql

    user_code,

    first_name,
    last_name,

    NULL AS password_hash,             -- INTENTIONALLY NULL: do not migrate plaintext password

    CAST(is_admin AS BOOLEAN) AS mfa_enabled,  -- ClientAdmin/PlatformAdmin: MFA enforced at login
    NULL  AS mfa_secret,               -- MFA secret set during first MFA setup
    CAST(is_manager AS BOOLEAN),
    CAST(is_admin AS BOOLEAN),
    CAST(is_active AS BOOLEAN),
    client_id,
    NULL AS intermediary_id,  -- populate in application layer when user type is set
    NULL AS adjuster_id,
    COALESCE(NULLIF(created_on, '1900-01-01'), NOW()),
    0
FROM InsureEdge_System_DEV.dbo.User2;

-- MANDATORY SECURITY VALIDATION after load:
SELECT COUNT(*) AS users_with_password FROM identity.app_user WHERE password_hash IS NOT NULL;
-- Must return 0. If > 0, STOP MIGRATION and investigate immediately.

SELECT COUNT(*) AS users_not_flagged FROM identity.app_user WHERE requires_password_reset = FALSE;
-- Must return 0. If > 0, UPDATE all rows: UPDATE identity.app_user SET requires_password_reset = TRUE;
```

```csharp
public class AccountBinaryExtractor : BackgroundService

    // Configuration

    private const int BatchSize = 1000;

    protected override async Task ExecuteAsync(CancellationToken ct)
    {
        // 1. Open SqlConnection to source SQL Server
        // 2. Query AccountBinary in batches:
        //    SELECT top {BatchSize} ab.AccountBinaryId, ab.FileName, ab.BinaryContent,
        //           ab.PolicyId, ab.ClaimId, ab.AdjusterId, ...
        //    FROM AccountBinary ab
        //    WHERE NOT EXISTS (
        //        SELECT 1 FROM MigrationManifest m WHERE m.SourceId = ab.AccountBinaryId AND m.TableName = 'AccountBinary'
        //    )
        //    ORDER BY ab.AccountBinaryId

        // 3. For each row with non-NULL BinaryContent:
        //    a. Determine entity type from first non-NULL FK column (PolicyId, ClaimId, etc.)
        //    b. Lookup ClientCode from identity.client via ClientId
        //    c. Construct blob path:
        //       string blobPath = $"{clientCode}/{moduleName}/{recordId}/{fileName}";
        //       (moduleName examples: "policy", "claims", "adjusters")
        //    d. Upload to Azure Blob:
        //       BlobClient blobClient = containerClient.GetBlobClient(blobPath);
        //       await blobClient.UploadAsync(binaryStream, overwrite: false);
        //    e. Write to MigrationManifest table:
        //       INSERT INTO MigrationManifest (TableName, SourceId, BlobPath, ByteCount, Checksum, ExtractedOn)
        //       VALUES ('AccountBinary', accountBinaryId, blobPath, byteCount, sha256Hash, NOW())

        // 4. Log summary: total extracted, total skipped (already done), total failed
        // 5. Idempotent: safe to re-run; skip already-extracted records
    }
```
